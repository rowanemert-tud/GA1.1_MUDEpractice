## Subtract function

The `subtract(a, b)` function subtracts `b` from `a` and returns the result.

It may fail if the values do not support subtraction.

## Add function

this code has an addition function. it adds two numbers
it may break if the syntax is typing in wrong

The `add(a, b)` function adds two values together and returns the result.

It may fail if the values cannot be added using the `+` operator.


### Example

```python
subtract(5, 2)
add(2, 3)
```
